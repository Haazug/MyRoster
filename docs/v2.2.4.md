# MyRoster v2.2.4

Based on main `ee56f2624678f3dc55538c5a4d8ddc7bf8593888`, preserving the existing mobile booking dialogs, progressive live discovery, radar sources and v2.2.3 features.

## Scheduled flights and reminders

A scheduled flight becomes delayed at its departure time and cancelled at departure + 3 hours if it has not taken off. New bookings explicitly store `takeoffAt: null`; opening preflight and legacy `startedAt` on a scheduled/delayed booking do not count as takeoff. A real takeoff prevents automatic cancellation. Notification deduplication cannot suppress cancellation persistence. Automatic updates are guarded against a changed schedule or a takeoff on another device.

In Trips, open Actions → Reschedule flight and choose a future local date and time. Scheduled, delayed and cancelled flights can be rescheduled; departed and completed flights cannot. The booking ID and route are retained, lifecycle markers are reset and the plan receives the new departure time. Reminder deduplication keys include that time. A preflight session for an old departure is invalidated when its active session is next checked.

Notifications require permission and a running page. Browsers may throttle or suspend background tabs. There is no push subscription, service worker push handler or server reminder scheduler in this repository: closing the site prevents timely notification delivery. On reopening, statuses are recalculated from absolute timestamps and only the latest applicable reminder is shown. Export the calendar event for reminders managed by the calendar application; after rescheduling, replace the previous event. Browser/OS notification display and calendar alert settings remain controlled by the user.

## Directory and live discovery

The locally hosted Departure Dots font is applied to airport/airline directory board identities, airline page headings and route rows, and the operated-route display. Supporting paragraphs and controls retain readable text fonts.

Live search supports translated singular/plural transatlantic terms and transcontinental terms, plus a Route type selector combined with the existing airline/status filters. Typing these terms in the main search also opens the filtered live list. Transatlantic uses the existing great-circle Atlantic corridor test. Transcontinental is defined here as endpoints in different geographic continents (North and South America separate; Russia classified as Europe, Turkey/Cyprus as Asia). Unknown endpoints are not classified. Classifications depend on resolved endpoint data; filters do not imply complete worldwide live coverage.

Small alliance symbols below the airline favourites/top strip link to Star Alliance, SkyTeam and oneworld pages, with translated descriptions and linked member airlines represented in the existing reference catalog. Membership is reference metadata, not a real-time membership service.

## Importing routes

Use the flight plan page's import area. Existing PLN/XML imports and drag-and-drop remain available. Add a PLN/XML/JSON/CSV file, paste route data, or paste an MSFS Planner share URL. All routes are validated before preview; multi-flight data has a route selector. Importing previews a plan and does not automatically book or launch every flight. Maximum input size is 2 MB, 500 routes, 5,000 waypoints per route.

Supported Volanta data is JSON containing a flight, an array, or `flights`/`routes`/`data` wrappers; CSV accepts normalized headers such as `Departure ICAO`, `Arrival ICAO`, `Flight Number`, `Aircraft Type`, `Distance NM`, `Duration Min`. Endpoints accept `departure`/`arrival`, `origin`/`destination` or `from`/`to`, including airport objects with ICAO/IATA codes. Optional waypoints accept `id`/`ident`, `latitude`/`lat`, `longitude`/`lon`/`lng`. This is a data importer, not a Volanta account/API connection. Arbitrary private Volanta links and undocumented export shapes are not guaranteed.

```json
{"flights":[{"departure":{"icao":"LPPT"},"arrival":{"icao":"KJFK"},"flightNumber":"TP209","aircraft":{"icao":"A339"},"cruiseAltitude":35000,"distanceNm":2920}]}
```

```csv
Departure ICAO,Arrival ICAO,Flight Number,Aircraft Type
LPPT,KJFK,TP209,A339
KJFK,LPPT,TP210,A339
```

MSFS URLs are restricted to HTTPS `planner.flightsimulator.com/share/<UUID>`, with no credentials, custom ports or arbitrary redirect following. Public JSON/XML route responses can be imported. The supplied example `https://planner.flightsimulator.com/share/0cc9ddc2-5e7f-4d90-b827-84c8dc8a68a6` currently redirects to the Planner sign-in page. MyRoster cannot import that private session directly: open the link in the Planner, sign in with the linked Microsoft/Xbox or PlayStation account, export PLN and import the file. This limitation is shown explicitly rather than treating the login HTML as route data.
